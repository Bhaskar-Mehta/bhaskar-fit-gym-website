# 💪 Responsive Gym Website — by Bhaskar Mehta

A fully responsive gym / fitness landing page built with HTML, CSS and JavaScript.

### Features
- Fully responsive layout — mobile first, then scaled up for tablet and desktop
- Smooth scroll animations on scroll (ScrollReveal)
- Active nav-link highlighting as you scroll through sections
- Built-in BMI (Body Mass Index) calculator
- Newsletter subscribe form with validation
- Sticky header, scroll-to-top button, and mobile hamburger menu
- Dark theme UI with a clean green accent

### Tech stack
- HTML5
- CSS3 (custom properties / CSS variables, Grid & Flexbox)
- Vanilla JavaScript
- [Remixicon](https://remixicon.com/) for icons
- [ScrollReveal](https://scrollrevealjs.org/) for scroll animations


### Run it locally
Just open `index.html` in your browser — no build step required.
